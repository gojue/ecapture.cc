# 场景案例

以下示例使用 eCapture v2.12.0，在自己的测试环境中触发请求并核对捕获结果。

- [Android 应用的 HTTPS 请求](./android.md) — 确认设备、系统 TLS 库和网卡，观察一次新连接。
- [Docker 容器中的 TLS 服务](./docker.md) — 从宿主机确认容器进程与实际加载的 OpenSSL 库。
- [TLS 加密的 gRPC 调用](./grpc.md) — 在终端查看增量消息，再用 Wireshark 检查 HTTP/2 流。
