## BaseProbe 生命周期与初始化
任何核心 TLS 探针的生命周期都始于 `Initialize(ctx, cfg)`。具体探针通过将共享的校验和调度器设置委托给 `base.BaseProbe.Initialize()` 来实现该方法。

在初始化期间，会进行配置校验、配置运行日志记录器、解析字节码选择模式，并实例化一个带有适当文本或发布者处理程序的事件调度器。

```mermaid
sequenceDiagram
    participant User as "命令行 / 控制器"
    participant Probe as "openssl.Probe / gotls.Probe"
    participant Base as "base.BaseProbe"
    participant Config as "domain.Configuration"
    participant Dispatcher as "events.Dispatcher"

    User->>Probe: Initialize(ctx, cfg)
    Probe->>Base: Initialize(ctx, cfg)
    Base->>Config: Validate()
    Config-->>Base: 成功 / 错误
    Base->>Base: 解析字节码选择器
    Base->>Dispatcher: NewDispatcher()
    Base-->>Probe: 初始化完成
    Probe->>Probe: 校验版本与特定配置
    Probe-->>User: 就绪
```

## eBPF 挂载与管理器设置
初始化完成后，探针的 `Start(ctx)` 方法会驱动加载 eBPF 字节码资产、初始化 `ebpfmanager.Manager`、挂载 kprobes/uprobes 并获取事件映射表（maps）。

字节码资产根据 BTF 和编译时模式配置进行动态选择，从嵌入的资产中读取，并通过 `ebpfmanager` 加载到内核中。

## 并发、停机与资源清理
探针的卸载由 `Stop(ctx)` 和 `Close()` 管理。`BaseProbe` 以原子方式管理运行状态，而具体探针则确保通过 `manager.CleanAll` 停止 eBPF 管理器以卸载探针并释放映射表，同时关闭文件句柄或读取器。

```mermaid
sequenceDiagram
    participant User as "调用者 / 上下文"
    participant Probe as "openssl.Probe / gotls.Probe"
    participant Base as "base.BaseProbe"
    participant Manager as "ebpfmanager.Manager"

    User->>Probe: Close() / Stop(ctx)
    Probe->>Manager: bpfManager.Stop(manager.CleanAll)
    Manager-->>Probe: 探针已卸载且映射表已释放
    Probe->>Probe: 关闭 Closer 资源 (closer[])
    Probe->>Base: Stop(ctx)
    Base->>Base: isRunning.Store(false)
    Probe-->>User: 资源已释放
```
