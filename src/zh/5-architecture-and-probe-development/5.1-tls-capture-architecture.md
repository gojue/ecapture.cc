# TLS 捕获架构

## 从挂载到捕获

CLI 通过工厂创建具体探针。各模块选择目标库或可执行文件，并设置 eBPF 管理器、挂载点、事件映射和解码器。`BaseProbe` 负责读取器和事件调度。管理器需要采集哪些记录，由捕获模式和文本数据源共同决定。

| 模式与数据源 | 采集记录 | 结果 |
| --- | --- | --- |
| `text` + `pcapng`（默认） | 选中接口的 TC 数据包，以及目标库或程序的 TLS 密钥事件 | pcapng 流进入实时解密 SDK，生成重建消息或显式选择的协议事件。 |
| `text` + `hook` | TLS 读写函数事件 | 按单次函数读写输出明文，供兼容场景使用。 |
| `keylog` | TLS 密钥事件 | 去重后的 NSS Key Log 行。 |
| `pcapng` | TC 数据包和 TLS 密钥事件 | 在 pcapng 文件中保存包和解密密钥块（DSB）。 |

逐步弃用的是通过明文读写函数采集文本的路径。默认的包解码路径仍依赖库或运行时探针采集密钥。[架构说明](https://github.com/gojue/ecapture/blob/v2.12.0/docs/agent/architecture.md) · [输出路径](https://github.com/gojue/ecapture/blob/v2.12.0/docs/agent/output-pipeline.md)

## 库与符号解析

- **OpenSSL/BoringSSL。** `tls` 模块按已识别的库版本选择具有相应偏移量的 eBPF 对象。内部连接记录可在分发前补充数据事件的上下文。OpenSSL 客户端随机数尚未初始化时，采集端会丢弃不完整的密钥快照，包括 `SSL_clear` 之后复用会话的情况。[OpenSSL 探针实现](https://github.com/gojue/ecapture/blob/v2.12.0/internal/probe/openssl/openssl_probe.go) · [版本记录](https://github.com/gojue/ecapture/blob/v2.12.0/CHANGELOG.md)
- **Go TLS。** 探针在指定可执行文件中解析函数，分别处理 Go 的栈和寄存器调用约定。常规 ELF 符号缺失时会尝试使用 Go 的符号信息。捕获模式决定需要定位明文读写函数还是写入密钥的函数。[GoTLS 符号解析](https://github.com/gojue/ecapture/blob/v2.12.0/internal/probe/gotls/config_symbol.go) · [GoTLS 探针实现](https://github.com/gojue/ecapture/blob/v2.12.0/internal/probe/gotls/gotls_probe.go)
- **GnuTLS。** 探针挂载前会校验版本，按实测布局选择对象。映射包括 3.8.10，上游 3.8.12 和 3.8.13 复用 3.8.11 的对象。[GnuTLS 配置和版本映射](https://github.com/gojue/ecapture/blob/v2.12.0/internal/probe/gnutls/config.go)

## C 与 Go 之间的二进制 ABI

内核事件记录有固定的二进制布局。读取器按 eBPF map 选择模块解码器，C 和 Go 两端的字段顺序、符号、宽度、填充及字节序必须一致。以下为 GoTLS **hook 文本源**的 `go_tls_event`，使用小端解码。

| 字节偏移 | 字段内容 |
| --- | --- |
| 0–15 | 64 位单调时间戳，随后为 32 位 PID 和 TID |
| 16–27 | 32 位有符号数据长度、单字节事件类型、3 个填充字节、32 位文件描述符 |
| 28–67 | 源和目的地址（各 16 字节）、端口、IP 版本及对齐字节 |
| 68–83 | 16 字节的进程名 |
| 从 84 开始 | 负载。解码器检查声明长度是否超过剩余字节数或 16 KiB 上限。 |

包模式使用另一套 ABI。TC 事件携带进程标识，在可用时也携带有长度限制的参数快照。pcapng 写入器会随包保留端点归属，并在增强包块（EPB）注释中保存 argv。下游解码事件因而能保留 PID、进程名、最多 256 字节的参数和明确的截断标记。无法确认归属时保留未知状态。[GoTLS 内核结构](https://github.com/gojue/ecapture/blob/v2.12.0/kern/gotls_kern.c) · [Go 解码器](https://github.com/gojue/ecapture/blob/v2.12.0/internal/probe/gotls/event.go) · [包元数据](https://github.com/gojue/ecapture/blob/v2.12.0/docs/agent/output-pipeline.md)
