# 进阶用法

v2.12.0 的三个核心 TLS 模块共用基于网络包的默认文本数据源和输出接口。排查捕获结果时，先确认采集器选择的网卡、目标库或 Go 程序，以及实际输出位置。

| 任务 | 从哪里开始 |
| --- | --- |
| 探针已经启动，但看不到预期请求 | 按[故障排查](4.1-tls-troubleshooting.md)核对网卡、TLS 握手、协议解析和输出目标。 |
| 把解码后的事件交给其他应用，或调整运行中探针的过滤条件 | 在[集成与部署](4.2-integration-and-deployment.md)中选择主动 TCP 连接或 WebSocket 订阅，并了解独立的 HTTP 配置接口。 |
| 观察 NSS 应用、Shell 命令或数据库查询 | 从[其他模块](4.3-other-modules.md)确认支持的平台及目标程序。 |
