# First GoTLS Capture

Use a Go client or server that you build and that makes HTTPS connections using `crypto/tls`. Choose a request with a recognizable path. You need the same ELF executable used by the running application. An executable from another build may have different function addresses.

## Select the executable and interface

```bash
sudo ecapture gotls --elfpath ./go-client --model text --text-source pcapng
```

Replace `./go-client` with your application path. `--elfpath` is required. On kernels 5.2 and later, `--pid` (`-p`) can also filter probe events by process ID. The default text source uses TLS secrets from that executable and packets from the selected interface. Specify `-i lo` if the client connects to a server on loopback. To keep a copy of the decoded records, add `--output stdout --output go.jsonl`. [GoTLS command options](https://github.com/gojue/ecapture/blob/v2.12.0/cli/cmd/gotls.go) · [Global filters](https://github.com/gojue/ecapture/blob/v2.12.0/cli/cmd/root.go)

## Verify with your workload

1. Wait for the probe to start. In a second terminal run the chosen client, or send an HTTPS request to the selected Go server. Open a fresh connection.
2. Look for an `event` line containing the request path and a response from the same connection. HTTP/2 requests can share a connection, so use the stream ID to pair each request and response.
3. If you see no matching message, check the executable and the interface in the startup log. For a QUIC test, a TCP-only packet filter would exclude the UDP traffic.

To keep the packets and secrets for an independent check, add `--pcapfile go.pcapng` to the same text command and follow the [Wireshark workflow](../3-capture-modes/3.6-wireshark-decryption-workflows.md). To inspect individual function read/write chunks during migration, specify `--text-source hook`. [GoTLS capture](../2-core-tls-modules/2.2-gotls-capture.md) describes symbol resolution and the three modes. [Output examples](https://github.com/gojue/ecapture/blob/v2.12.0/docs/example-outputs.md)
