# First GnuTLS Capture

On Linux, choose an application linked to a supported version of `libgnutls.so`. For example, use a curl build whose `curl -V` output names GnuTLS. The Android collector omits the `gnutls` command.

## Capture an HTTPS transaction

```bash
sudo ecapture gnutls --model text --text-source pcapng
```

The collector searches common library paths and identifies the patch version to select a matching layout. If the application uses a private installation, pass its actual shared library with `--gnutls /path/to/libgnutls.so.30`. Check the interface named at startup, and use `-i lo` for loopback traffic.

With eCapture running, start the GnuTLS-backed client and request a known path on your test HTTPS server. Use a fresh connection to capture the handshake. The terminal labels decoded records `log_type=event` and `module=gnutls`. Look for the request path and its response. A handshake diagnostic or a growing file alone does not verify decryption.

## Keep the evidence for Wireshark

```bash
sudo ecapture gnutls --model pcapng --pcapfile gnutls.pcapng
```

Run the request again while this capture is active, stop it with `Ctrl+C`, and open the file in Wireshark. To supply keys for a separate packet capture, use `--model keylog --keylogfile gnutls.keys` during the same connection.
